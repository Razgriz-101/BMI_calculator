# BMI計算機

Tkinter製のBMI計算アプリです。ユーザーごとに測定履歴を保存し、BMI・身長・体重の推移をグラフで確認できます。

## 起動方法

Python 3で次のファイルを実行します。TkinterとSQLiteはPython標準ライブラリを使用します。

```powershell
python BMI_cal.py
```

初回起動時は「新規登録」からアカウントを作成してください。ユーザー名は1〜32文字、パスワードは8〜128文字です。

## BMIの計算

測定日・身長・体重を入力し、「計算して保存」を押します。測定日は年・月・日を個別に選べます。「カレンダー」から日付を選ぶこともでき、初期値はPCのシステム日付です。身長はcm、体重はkgで入力します。BMIは次の式で計算し、小数第3位まで表示します。区分判定には丸める前の値を使います。

```text
BMI = 体重(kg) ÷ 身長(m)²
```

| BMIの範囲 | 区分 |
| --- | --- |
| BMI < 16.0 | 低体重（痩せすぎ） |
| 16.0 ≤ BMI < 17.0 | 低体重（痩せ） |
| 17.0 ≤ BMI < 18.5 | 低体重（痩せぎみ） |
| 18.5 ≤ BMI < 25.0 | 普通体重 |
| 25.0 ≤ BMI < 30.0 | 肥満予備軍（過体重） |
| 30.0 ≤ BMI < 35.0 | 肥満（1度） |
| 35.0 ≤ BMI < 40.0 | 肥満（2度） |
| BMI ≥ 40.0 | 肥満（3度） |

BMIは身長と体重から算出する目安です。体脂肪率などによって実際の状態は異なります。

## 履歴とグラフ

正常に計算できた測定日・身長・体重・BMIをSQLiteに保存します。計算画面には次のグラフを常時表示し、測定を保存するとすぐ更新します。

- BMIの推移。背景色と凡例でBMI区分を示します。
- 身長と体重の推移。身長は左軸（cm）、体重は右軸（kg）で表示します。

身長欄には、ログイン中のユーザーの最新履歴に記録された身長を初期表示します。

メニューバーの「データ」→「過去のデータを編集…」から履歴一覧を開けます。行を選んで編集すると、カレンダーで測定日を選び直し、身長・体重も変更できます。保存時にBMIを再計算し、編集結果を一覧とグラフに反映します。

過去履歴のないアカウントでは、初回ログイン時にグラフ表示用の月次サンプルを過去5年分登録します。サンプル値は架空の値で、グラフでは実測と同じスタイルで表示します。初回の実測を保存した後もサンプル履歴は残ります。

## アカウントと保存先

アカウントと測定履歴は、このPC上のSQLiteデータベースに保存されます。アカウントごとに履歴を分け、パスワードはソルト付きハッシュとして保存します。サーバーへの送信やアカウント同期は行いません。

「次回から自動ログイン」を選ぶと、同じWindowsユーザーで次回起動した際にログイン画面を省略します。ログアウトすると自動ログイン設定を解除します。

Windowsでの保存先:

```text
%LOCALAPPDATA%\BMI_calculator\bmi_history.sqlite3
```

ログイン画面は540×620、計算画面は1260×760の固定サイズで表示します。

## ソース構成

- `BMI_cal.py`: 起動用エントリーポイント
- `app.py`: 画面遷移とBMI入力画面の制御
- `auth_screen.py`: ログインとユーザー登録
- `storage.py`: SQLite、認証情報、測定履歴
- `date_picker.py`: 年・月・日選択とカレンダー
- `history_graph.py`: BMI・身長・体重のグラフ
- `history_editor.py`: 過去データの一覧と編集
- `bmi_logic.py`: BMI計算と区分判定
- `ui_style.py`: 共通の配色、ボタン、入力欄

モジュール間の依存関係とデータの流れは [ARCHITECTURE.md](ARCHITECTURE.md) を参照してください。
